# Forge Pass — complete 198-artwork collection

**99 Preview · 66 Motion · 33 Volumetric**

The full art collection contains **198 PNGs + 99 animated GIFs**, approximately **3.60 GB** across 44 independent ZIP files. Every ZIP opens separately; download all art ZIPs below for the complete collection.

- PNG masters: 2048 × 2048 pixels.
- GIFs: 1000 × 1000 pixels, 20 fps, infinite loop, each below 50 MB.
- Motion: 24-second branch rotation with a counter-rotating outer ring.
- Volumetric: 12-second separation and merging of front/rear branches, with an expanding and contracting halo.
- The central hub stays fixed in both animated tiers.
- Each animated artwork includes its own PNG still. Preview artworks are static.

[View the collection overview](ForgePass_198_Overview.jpg)

## Optional automatic download

If Python 3 is installed, download [Download All](https://github.com/aygaladima/New/raw/refs/heads/forge-pass-sample-download/ForgePass_198_Download_All.py), put it in the folder where you want your collection, and run `python ForgePass_198_Download_All.py`. It downloads, verifies, and extracts all 297 art files. It resumes completed artwork on later runs and removes only its own temporary ZIPs after extraction. No Python packages are required.
